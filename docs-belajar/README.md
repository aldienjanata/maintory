# Dokumentasi Belajar Maintory 📚

Folder ini berisi dokumentasi lengkap tentang cara kerja aplikasi Maintory, ditulis khusus dengan bahasa yang ramah pemula untuk membantu Anda memahami konsep *programming* di baliknya.

### Daftar Isi Dokumen:

*   📖 **[00-ringkasan.md](./00-ringkasan.md)** - Halaman pengantar, peta dokumen, dan daftar pertanyaan sering muncul.
*   🏛️ **[01-arsitektur.md](./01-arsitektur.md)** - Penjelasan gambaran besar sistem (Frontend, Vercel, Supabase) dan struktur folder.
*   🛡️ **[02-keamanan-security.md](./02-keamanan-security.md)** - Hasil audit keamanan aplikasi, bahaya *env vars*, dan aturan akses RLS.
*   ⚙️ **[03-fitur-fitur.md](./03-fitur-fitur.md)** - Peta lengkap seluruh fitur halaman beserta alur logikanya.
*   🚑 **[04-maintenance-troubleshooting.md](./04-maintenance-troubleshooting.md)** - Buku panduan perbaikan (debug) jika web tiba-tiba mati atau error.
*   ⚖️ **[05-kelebihan-kekurangan.md](./05-kelebihan-kekurangan.md)** - Analisis jujur mengenai kelebihan arsitektur ini dan batasannya di masa depan.
*   🧠 **[06-fondasi-belajar.md](./06-fondasi-belajar.md)** - Penjelasan 8 konsep dasar *programming* yang dipakai di aplikasi ini (Sangat disarankan!).
